# AntiRC 1.0.0 (15) TestFlight 发布记录

日期：2026-11-21（Asia/Shanghai）。基于 1.0.0 (14)。

## 会话页顶部栏精简

1. **删除无效的“新建对话”按钮**：它在网页首页找不到对应按钮，会退回发送模拟的 Cmd+N，但网页不响应，而且没有错误提示，所以点了没反应。新建对话请使用网页里的输入框或项目旁的 `+`。
2. **删除重复的“重新加载”菜单项**：网页自带的刷新按钮、下拉刷新和悬浮控制球都可以刷新。
3. **顶部栏改为单行窄条**：返回、标题加状态点、⋯ 菜单。按钮图形 34pt，点击区域保持 44pt。导航栏高度减少约 17pt（状态栏安全区由系统占用，无法压缩）。
4. **“网页后退”移入 ⋯ 菜单**：只在网页可后退时显示，避免与 App 的返回按钮并排造成误点。侧滑和悬浮控制球也可以后退。
5. ⋯ 菜单现在包含：切换 Google 账号、网页后退、显示悬浮控制球（隐藏时）、分享连接、断开连接。

## 验证
