# AntiRC 1.0.0 (14) TestFlight 发布记录

日期：2026-11-21（Asia/Shanghai）。

## 账户登录与切换

1. **新电脑不再被锁死在其他电脑的账号上**：首次连接时沿用最近使用的账号编号，只作为第一次请求的推测，不写入记录、不做纠正重试；对话或项目同步成功后才保存为这台电脑的偏好。实例断开时提示“沿用了账号 #N，可切换”。
2. **弹窗或重定向方式的账号切换不再被撤销**：账号菜单以新窗口、重定向或点击打开的 `?authuser=N` 都统一转为保留当前实例与会话的切换；用户在 Google 页面主动完成的添加账号、重新登录等流程，回到远程页面后以落地账号为新选择。
3. **编号漂移时请用户确认**：同一编号下识别到的邮箱与记录不同，或纠正后仍落在其他编号时，显示提示卡片（切换账号 / 以当前账号为准），不再静默覆盖。
4. **原生账号切换菜单**：列出本机见过的账号，并提供打开网页账号菜单、添加其他账号、退出 App 内所有 Google 账号的选项；网页没有头像时会给出提示，不再无反应。
5. **连接状态真实可信**：启动时清除上次遗留的“已连接”；同一时间只有当前会话显示为已连接；页面就绪才显示已连接，失败或实例断开显示未连接，等待登录显示“等待登录 Google”。
6. 清除网页缓存或删除正在使用的记录时，同时结束当前会话。

## 其他修复

- 悬浮控制球接入会话页（终端键、刷新、沉浸全屏等），展开面板固定在底部，不会超出屏幕。
- 实例断开检测改为节流扫描文本节点，降低流式输出时的卡顿和耗电；单页应用重新连上实例时自动撤下提示。
- 剪贴板只检测“可能有链接”，点“连接”后才读取并校验，不再每次启动触发粘贴授权提示；横幅可以关闭。
- 局域网地址按主机名判断，路径里的“10.”不会再被误判为局域网。
- 非 Google 外部链接交给系统浏览器打开，不再替换远程会话页。
- 后台网页进程被系统回收后自动重新加载，避免白屏。
- 拒绝相机权限时，扫码页也提供“手动输入连接地址”。
- 文案：AtGravity 拼写、“修改设备名称”、历史记录状态文字、缺失的菜单图标。
- 清理：删除未编译的重复 `Design/DesignSystem.swift`、不可达的手动输入卡片、只写不读的邮箱偏好（启动时删除旧值）及死代码。

## 验证

1. 原生 `AccountRecoveryTests`：21 项通过（新增推测账号、弹窗切换、重定向切换、用户主动账号流程、自动登录跳转仍纠正、邮箱不一致、状态重置等测试）。
2. JavaScript：23 项通过。
3. 模拟器冒烟：大厅、相机拒绝后的手动输入、会话页状态、悬浮球面板、原生账号菜单及“无头像”提示均正常；重启后旧的已连接状态已清除。

5. 未完成：真实 Google 多账号登录、切换、杀进程重开的真机验收。
